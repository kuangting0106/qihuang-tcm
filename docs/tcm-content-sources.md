## 一、标注规则

| 标签 | 含义 | 例子 |
|---|---|---|
| 原文 `quote` | 经典原句，保留原条号 | 《伤寒论》第 12 条桂枝汤原文 |
| 摘录 `paraphrase` | 药典、标准或教材的归纳 | 药典对甘草性味、功效的摘录 |
| 后世方解 `analysis` | 后世医家/教材分析 | “桂枝为君”“调和营卫” |

四个原则：

1. 每个知识点必须挂 `citationIds`；没有出处的内容不进入数据。
2. 经典原文、药典/标准、教材归纳分开，不把教材归纳写成经典原文。
3. 方剂出处必须写具体古籍：张仲景《伤寒杂病论》的伤寒部分标《伤寒论》，杂病部分标《金匮要略》；傅青主医书标具体书名（如《傅青主女科》）。不得用“方剂学”代替古籍出处。
4. 查不到确切出处的字段宁可不写；例如《伤寒论》第 12 条未列桂枝汤加减，页面就不硬编。

### 药性基础法则

本草列表顶部增加可悬停预览、点击固定的「药性基础法则」思维导图，数据在 `scripts/content/herb-principles.mjs`，共 6 组：

1. 三品分类：上品养命、中品遏病、下品除邪；“养生 / 遏病 / 除邪”是今语概括。
2. 四气五味：四气寒热温凉，五味辛甘酸苦咸；酸收涩、苦泄燥坚、甘补和缓、辛散行、咸软坚下、淡渗泄。
3. 气味阴阳：气为阳、味为阴；气厚阳中之阳、气薄阳中之阴；味厚阴中之阴、味薄阴中之阳；气薄发泄、气厚发热；味厚泄、味薄通。
4. 升降浮沉：味薄升而生、气薄降而收、气厚浮而长、味厚沉而藏、味平化而成；酸咸无升、甘辛无降、寒无浮、热无沉。
5. 药质与部位：枝达四肢、皮达皮肤、心与干内行脏腑；质轻上入心肺、质重下入肝肾；中空发表、内实攻里；枯燥入气分、润泽入血分。
6. 配伍七情：单行、相须、相使、相畏、相杀、相恶、相反。

校核说明：

- 通行本《本草备要·药性总义》作“气厚者浮而长；味厚者沉而藏”，不能合并成“气厚主浮而藏”。
- “辛能润”见于《本草备要》，但不是所有辛味药都润，页面已注明。
- “金石重镇安神”是后世归纳，不能推广为所有金石药都能安神；朱砂等有毒，页面提示须遵医嘱。
- “相需”通行作“相须”；“相恶”指一药削弱另一药功效，不是“取其一用”。

### 剂量换算与今用剂量

- 计量换算采用 **“一两 = 现今的一钱”**，在方剂组成区单独标注；这是本站统一折算约定，不是《伤寒论》原文，汉代度量衡考证另有异说。
- 原方剂量（两、升、枚）与今用剂量（钱、个）分栏显示，不混算；比例也只在同一单位组内比较。
- 小柴胡汤今用剂量按常用配比录入：柴胡 5 钱、黄芩 3 钱、人参 3 钱、半夏 5 钱、甘草 3 钱、生姜 3 钱、大枣 12 个（劈），比例 **5:3:3:5:3:3**（柴、芩、参、半、草、姜；大枣按个单独计量）。
- 桂枝汤按“一两 = 一钱”直接折算为桂枝 3 钱、白芍 3 钱、生姜 3 钱、甘草 2 钱、大枣 12 枚，比例 **3:3:3:2**；这是折算参考，不是临床处方。
- 今用剂量只作经方学习参考，实际用药由执业中医师辨证决定。
- 关系图谱的“本方中作用”（如柴胡疏肝胆、黄芩清热）为后世方解/讲义归纳，不是《伤寒论》原文；页面悬停显示，并明确标注“后世方解”。
- 方义解说由 `meaning.herbMeanings` 逐味录入，`meaning.summary` 汇总主治；均属后世方解，不冒充原书原文。
- 现代煎煮法、现代服用法分别放在 `preparation.modernDecoction` 与 `preparation.modernAdministration`，页面标“参考”，不是原书文字；各方剂可按实际调整。
- 现代克数/片数用量放在 `modernGramDoses`，页面“01 药材选取”卡可切换查看，并固定提示“本站中使用方剂用量不等于实际处方的用量”。
- 方剂详情页的“历代医家解说”栏预设两种占位：`古籍条曰`（某古籍中条曰：……）与`历代医家解说`（某医家曰：……）。收到内容后按“书名 · 卷/条 · 原文”替换，不把当代教材放进去。

- 也可在网页里直接点“添加解说”填写并“保存到本浏览器”。这利用浏览器 `localStorage`，只对当前浏览器生效，不会写入公开数据；保存后可点“查看数据代码”，把生成的 `modernExplanation` 片段粘贴到 `formulas.mjs` 对应方剂，重新构建后才永久上线。
- 原文悬浮注解由编者手动配置 `originalAnnotations`：`phrase` 是原文中要标注的词句，`note` 是悬停显示的文字，`citationIds` 标注解说依据。未配置的词句不显示悬浮层。

## 八、本草三经与功效分类

- **三经**：上经（益气延年养生）、中经（治病）、下经（治大病或有微毒）。名目与“上药/中药/下药”的分层依据见《神农本草经》序录；页面另加“益气延年养生 / 治病 / 治大病或有微毒”作为阅读标签。
- **十二功效分类**：解表药、清热药、泻下药、祛风去湿利水药、理气消食药、止血凉血药、活血化瘀药、止咳平喘化痰药、温中补虚药、收敛固涩药、安神开窍药、攻坚去实去寒药。这些是本站导航标签，不是《神农本草经》原文。
- 同一味药可同时属于一个三经层级和多个功效分类；归类数据在 `scripts/content/herb-taxonomy.mjs`，构建时写入每味药的 `classicRankId` 与 `therapyCategoryIds`，校验脚本会检查引用是否存在。
